> **Public-submission boundary.** The Vercel endpoint serves the public, real-data Aegis desk. Public field contributions and responses are deliberately unattributed. They cannot increase Aegis confidence, alter its risk score, or authorise an action. The Vercel deployment has no persistence service configured, so public text context remains only in the current browser session; the managed full-stack runtime persists public records and was verified with self-cleaning probes. Optional photo extraction still requires storage and server-side model credentials in the deployment environment.
