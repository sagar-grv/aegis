# InsightLoop — 2-Minute Demo Script

Use a real authenticated learner account and non-sensitive academic work. Do not expose personal data or project settings.

| Time | Action | Suggested narration |
|---|---|---|
| 0:00–0:15 | Show landing and sign in. | “InsightLoop is a misconception-first adaptive learning platform for STAMPERS Track 04. It starts with real learner reasoning, not a generic dashboard.” |
| 0:15–0:40 | Enter a topic, original question, reasoning, and confidence. | “The learner shares their method and confidence, because an answer alone cannot explain a misconception.” |
| 0:40–1:05 | Submit and show the insight. | “The server validates structured AI feedback: an explainable misconception hypothesis, bounded mastery and confidence, and constructive feedback.” |
| 1:05–1:30 | Show next probe and path. | “InsightLoop writes one next diagnostic question that tests the precise target skill, then saves it as the learner’s topic path.” |
| 1:30–1:50 | Switch to Teacher Lens as an authorised account. | “Teacher Lens aggregates genuine workspace submissions only. It does not invent a class profile.” |
| 1:50–2:00 | Pause on safeguards. | “InsightLoop supports learning reflection; it does not grade automatically or make claims about a learner beyond submitted work.” |
