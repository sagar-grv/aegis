# CrisisGrid — 2-Minute Demo Recording Script

## Recording Setup

Record the deployed CrisisGrid site in a desktop browser at 1440px width. Keep the browser chrome minimal, begin on the initial situation board, and show only the application—not source files or private account information. The full demo should take approximately two minutes.

## Spoken Script and Actions

| Time | On-screen action | Suggested narration |
|---|---|---|
| 0:00–0:15 | Start on the command board. Pause on the map and Decision Receipt. | “CrisisGrid is an explainable crisis-response coordination platform for the STAMPERS Open Innovation track. It helps a command team decide where limited resources should go when information and infrastructure are failing.” |
| 0:15–0:33 | Point to the selected Farakka East zone and receipt. | “Instead of showing an opaque high-risk label, CrisisGrid generates a Decision Receipt. It shows the priority score, people potentially isolated, confidence, and the contributions from life-safety exposure, water rise, route access, and report reliability.” |
| 0:33–0:50 | Click **Mesh Fallback**. | “The hard-mode scenario assumes that forty percent of communication infrastructure is unavailable. When fallback mode is activated, CrisisGrid shifts to cached road-graph and SMS-relay information, and it makes the reduced route confidence visible.” |
| 0:50–1:07 | Click **Raghunathganj** on the map. | “A coordinator can inspect a different zone immediately. The decision receipt and confidence update, so the rationale for the new priority is always visible.” |
| 1:07–1:24 | Click **Approve dispatch**. | “CrisisGrid does not hide human responsibility. The operator approves the recommendation; then the boat unit, destination, route, and remaining capacity update in the decision log and resource ledger.” |
| 1:24–1:45 | Click **Log SOS**, then queue the receipt. | “Citizens or field teams can submit a light-weight SOS report. In degraded connectivity, this receipt is stored locally for later relay instead of being silently lost.” |
| 1:45–2:00 | Close the modal and pause on the final board. | “CrisisGrid brings crisis mapping, explainable prioritisation, route viability, resource coordination, citizen reporting, and low-connectivity resilience into one calm command surface. All data shown here is simulated for the prototype.” |

## Submission Video Checklist

Before publishing the video, confirm that the title identifies **CrisisGrid** and **STAMPERS National Hackathon 2026**, the video is publicly viewable by anyone with the link, the audio is intelligible, and the video description contains the deployed URL and GitHub repository URL. Use an unlisted YouTube video, Loom, Google Drive link with public viewing, or another accessible video host accepted by the organiser.
